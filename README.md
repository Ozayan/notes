## Como organizo meu aprendizado

Para cada novo assunto, procuro seguir este processo:

1. **Estudar:** consultar o conteúdo da faculdade, cursos e documentação confiável.
2. **Compreender:** reescrever o conceito com minhas próprias palavras.
3. **Praticar:** executar um exercício ou laboratório quando aplicável.
4. **Registrar:** documentar comandos, resultados, erros e aprendizados.
5. **Revisar:** corrigir e complementar a nota conforme avanço no tema.
6. **Aplicar:** relacionar o conhecimento a situações de suporte e projetos pessoais.
